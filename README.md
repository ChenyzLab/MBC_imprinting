# MBC_imprinting
These are scripts and related files for DMS and scMulti-omics analysis.

## Data availability
Raw sequencing data of DMS and scRNA-seq have been deposited in the Genome Sequence Archive (GSA) under the accession number CRA026328 and HRA011767. 

## Folders structure
DMS folder contains: 1) files to generate condon variant table and escape score. 2) analysis pipeline and visualization scripts

scMulti-omics folder contains: 1) Scripts for single cell multi-omics dataset analysis.

## Citation
This code was used to analyze deep mutational scanning(DMS) data and single cell multi-omics data for the project

"Tunable immune imprinting of memory B cells to SARS-CoV-2 variants"
